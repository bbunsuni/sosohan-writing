# 디자인 방향 (Design Handoff)

`pre-design` → `authentic-web-design` 순서로 정한 디자인 기준입니다. 화면을 새로 만들거나 고칠 때 이 문서를 먼저 확인합니다.

## Brief

> **톤 재설정** — 일상의 짧은 글을 쓰고 읽는 사람들을 위해, 글을 쓰고 같은 주제의 이야기를 읽는 행동이 가장 먼저 보이도록.
> 따뜻한 종이 색감과 세리프 제목은 유지하고, **Editorial** 방향으로 정리한다.
> 완료 기준: 화면마다 핵심 버튼 하나, 이모지 아이콘 없음, 반복 카드 없음, 본문 줄 길이 65ch 이하, 모바일·데스크톱에서 위계 유지.

## Handoff

| 항목 | 내용 |
| --- | --- |
| Intent | 글을 **쓰는** 곳이자, 같은 주제의 글을 **읽는** 곳. 장식보다 글이 주인공 |
| Preserve | 웜 페이퍼 배경, 고운바탕(제목)·Noto Sans KR(본문) 조합, 주제 → 글 구조, "공감" 용어 |
| Change | 이모지 아이콘 → Lucide 라인 아이콘 / 반복 둥근 카드 → 구분선 리스트 / 중앙 정렬 히어로 → 왼쪽 정렬 / 핵심 버튼 2개 → 1개 / 균일한 간격 → 그룹 안은 촘촘, 섹션 사이는 넉넉 |
| Direction | Editorial — 타이포그래피 중심, 웜 뉴트럴(Stone), 강조색 1개 |
| Primary action | 홈: 글 쓰러 가기 · 글쓰기: 저장 · 그 외 화면: 헤더의 "글쓰기"만 강조 |
| States | 링크·버튼 hover / focus-visible 링 / 공개 범위(나만 보기·함께 나누기) / 빈 주제 |
| Constraints | 실제 데이터 연동 전까지 샘플 데이터 사용(수치는 샘플임), `prefers-reduced-motion` 존중 |
| Verification | 빌드·린트·타입 검사, 데스크톱 1280px·모바일 390px 실제 렌더 확인 |

## Tokens

| 역할 | Light | Dark |
| --- | --- | --- |
| paper (배경) | `#F9F8F6` | `#0F0E0D` |
| surface (입력창 등) | `#FFFFFF` | `#1A1817` |
| ink (제목·본문 강조) | `#1C1917` | `#F5F5F4` |
| body (본문) | `#44403C` | `#D6D3D1` |
| muted (보조 텍스트) | `#78716C` | `#A8A29E` |
| line (구분선) | `#E7E5E4` | `#292524` |
| accent (핵심 행동) | `#B45309` | `#F59E0B` |

- **서체**: 제목·글 본문 = 고운바탕, UI·메타 = Noto Sans KR. 굵기는 400 / 500 / 700만.
- **크기**: Display 44–56 · H1 32 · H2 24 · H3 20 · Body 16 · Small 14 · Caption 12 (px)
- **간격**: 8pt 기준(4, 8, 12, 16, 24, 32, 48, 64, 96). 내부 여백 ≤ 외부 여백.
- **모서리**: 버튼·입력 8px, 큰 카드 없음. 그림자 없음.
- **아이콘**: Lucide React, 16–18px, stroke 1.75.
- **모션**: `opacity`·`color` 전환만, 150ms ease-out.
